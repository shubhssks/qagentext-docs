# Contributing

Help make browser testing easier to understand. This repository welcomes:

- Clearer instructions and corrected control names.
- Small, independently written examples using dummy data.
- Accessibility improvements to documentation and examples.
- Reproducible bug reports and focused feature requests.

The extension implementation is private. Do not add extension source, bundles,
source maps, signing keys, environment files, customer tests or sensitive internal
details. Do not copy material from the private repository into a contribution.

## Propose A Documentation Change

1. Read the relevant guide and identify the smallest useful correction.
2. Use current user-facing labels and explain any version-specific behavior.
3. Test instructions on a safe page where possible; state what you verified.
4. Check links, spelling, keyboard access and image alternative text.
5. Remove sensitive data and submit a focused pull request after publication.

Keep one topic per change. Do not introduce unverified performance promises,
compliance claims, endorsements or keyword stuffing. Mark proposed behavior as
proposed, not shipped. Screenshots must show genuine UI and dummy data.

## Examples

Examples must be original, small, locally runnable and independent of extension
internals. Explain setup, expected result and limitations. Avoid external services,
tracking, secrets and destructive actions. Do not include copied third-party code
unless its license and attribution have been reviewed.

## Review

Maintainers review clarity, accuracy, safety and scope. A documentation correction
does not authorize a product release or publication. License terms for this draft
must be selected by the owner before accepting public contributions; do not infer
an open-source license for the private extension from this documentation repo.
