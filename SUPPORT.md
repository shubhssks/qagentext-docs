# Support And Feedback

For installation and first use, start with the [quickstart](docs/quickstart.md)
and [FAQ](docs/faq.md).

When this repository is published, use its Issues tab for public, non-sensitive
questions and the supplied bug/feature templates. While this is a local review
draft, use the support link on the
[Chrome Web Store listing](https://chromewebstore.google.com/detail/qagentext-qa-testing-agen/fmabdhbonhmnomjogiehbhadalondhch).

## A Useful Bug Report

Include your QAgentExt version, Chrome version, operating system, concise steps,
expected result and actual result. A small dummy page and sanitized screenshot
are more useful than a large private recording. For accessibility problems,
include keyboard steps and assistive-technology details if relevant.

Do not post credentials, private URLs, browser profiles, HAR files containing
tokens, extension packages or customer data. Inspect every attachment manually.
Use [SECURITY.md](SECURITY.md) for potentially sensitive security reports.

## Feature Requests

Describe the task you are trying to finish, what currently blocks you, and the
smallest change that would help. Explain who benefits and give a safe example.
Requesting a feature does not imply a release commitment or support deadline.
